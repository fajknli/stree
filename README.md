# stree

> 纯 Unix 管道驱动的声明式终端 TUI 响应引擎。

`stree` 是一个通用的终端树形视图引擎。它不绑定任何特定业务，不硬编码任何业务逻辑。它的职责极其纯粹：接收标准化的 TSV 数据流与关联表，将其渲染为可交互的多面板 TUI，并将用户的交互意图精准路由给外部脚本。

它是 `fzf` 的树形多维升级版，也是构建终端知识库、进程树、日志浏览器或任何结构化数据浏览器的通用底座。

---

## 核心架构特性

### 1. 协议驱动与零业务侵入
引擎不理解你的数据是文件、进程还是 JSON 节点。只要你能用 `awk` 吐出标准的 4 列 TSV 数据流，`stree` 就能将其转化为带预览的交互树。所有业务逻辑（数据获取、校验、写操作）全部由外部胶水脚本完成。

### 2. 正交声明式布局 (Orthogonal Declarative Layout)
彻底抛弃了“边框即状态”的黑魔法。布局语法将**几何尺寸**与**视觉边框**完全解耦：
*   **尺寸维度 `()`**：支持百分比（如 `50%`）与绝对值（如 `3` 行/列）。未声明尺寸的节点将均分剩余空间。
*   **边框维度 `[]`**：支持 `box`（默认）、`line`（单顶线）、`none`（无边框）。
引擎采用类似 Flexbox 的分配算法：优先扣除绝对尺寸，剩余空间按百分比分配，彻底消灭像素缝隙。

### 3. IPC 定向局部刷新
外部脚本执行完毕后，可通过 Unix Socket 调用 `stree update <窗口名>` 精准推送新数据。引擎仅重绘指定组件，绝不全量重绘，实现真正的零延迟局部刷新。

### 4. 双轨制执行模型 (Dual-Track Execution)
*   **默认模式**：引擎退出 Alternate Screen，交出 TTY 控制权。完美兼容 `vim`、`fzf`、`less` 等需要全屏接管的重型交互工具。
*   **`@` 静默模式**：在绑定命令前加 `@`（如 `@switch-view.sh`）。引擎保留 TUI 状态，底层切断子进程的 fd 管道继承（杜绝死锁），配合 IPC 实现零闪烁、零卡顿的后台状态切换。

### 5. 标签集样式引擎 (Tag-Set Style Engine)
第四列（状态列）不再是单一字符串，而是逗号分隔的**标签集**（如 `live,note,inbox`）。样式引擎采用“后规则覆盖”机制，支持多维度样式的叠加与优先级控制，用极少的配置实现极其细腻的视觉反馈。

### 6. 内存缓冲与零 I/O 预览
移动光标时，若预览目标未发生变化，引擎直接复用内存缓存（`cached_entity_id`），绝不重复 fork 进程。万级节点下滚轮操作依然丝滑。

## 协议规范

### 实体数据流 (stdin)
标准输入必须为 4 列制表符（`\t`）分隔的文本流：
```text
ID \t Display \t Path \t Tags
```
*   **ID**：全局唯一标识符，用于树形关联与状态记忆。
*   **Display**：在树形列表中展示的纯文本。
*   **Path**：业务负载。引擎不解析此字段，仅在触发快捷键时原样透传给外部命令。
*   **Tags**：逗号分隔的标签集（如 `live,archived,idea`）。用于样式引擎匹配与业务层状态过滤。

### 关联表 (--relations)
通过 `--relations <file>` 传入父子关系文件，格式为 2 列 TSV：
```text
Parent_ID \t Child_ID
```
引擎根据此表在内存中构建离散的树形拓扑。未在任何关系中作为子节点出现的 ID，将自动成为根节点。

## 布局与组件语法

### 布局字符串 (--layout)
语法：`area(size)[border]:Name`
*   `size`：`50%`（百分比）或 `3`（绝对行数/列数）。留空则参与剩余空间均分。
*   `border`：`box`（默认）、`line`、`none`。留空默认为 `box`。
*   `Name`：组件挂载的唯一标识符。

**示例**：
```text
vertical(
  horizontal(area(50%):MainTree, area(50%):Preview),
  area(1)[none]:Status
)
```
*解析：外层垂直布局。上方为水平布局（左侧 MainTree 占 50%，右侧 Preview 占 50%）；下方为绝对高度 1 行、无边框的 Status 区域。*

### 组件挂载
*   `--tree "Name:reload_script.sh"`：挂载树形组件，并绑定数据源脚本（用于初始化与 SIGUSR1 热重载）。
*   `--view "Name:command_template"`：挂载预览组件。支持占位符，享受内存缓存。
*   `--statusbar "Name:format_template"`：挂载状态栏。支持引擎内置变量（如 `{stree_visible}`）。

## 上下文占位符

在 `--view`、`--bind` 和 `--statusbar` 的命令模板中，支持以下占位符：

| 占位符 | 说明 |
| :--- | :--- |
| `{id}` | 当前选中节点的 ID |
| `{path}` | 当前选中节点的 Path |
| `{ids}` | 所有被标记（多选）节点的 ID 列表（空格分隔） |
| `{paths}` | 所有被标记节点的 Path 列表（空格分隔，自动转义引号） |
| `{window}` | 当前触发事件的窗口名称 |
| `{width}` | 当前 View 窗口的内部物理宽度（字符数） |
| `{height}` | 当前 View 窗口的内部物理高度（行数） |
| `{stree_visible}` | 当前焦点树可见节点数 |
| `{stree_total}` | 当前焦点树总节点数 |
| `{stree_marked}` | 当前焦点树被标记的节点数 |

## 双轨制执行与快捷键 (--bind)

快捷键绑定语法：`--bind "key=command"`

### 默认模式（全屏交互）
```bash
--bind "enter=vi {path}"
```
按下 Enter 时，`stree` 会隐藏 TUI，将终端控制权交给 `vi`。`vi` 退出后，`stree` 恢复并自动触发数据源重载。

### `@` 静默模式（零延迟切换）
```bash
--bind "ctrl-t=@switch-view.sh"
```
按下 Ctrl-T 时，`stree` **不会**退出 TUI。`switch-view.sh` 在后台静默执行（其 stdout/stderr 被丢弃以切断管道死锁）。脚本执行完毕后，可通过 IPC 推送新数据，实现无闪烁的视图切换。

## IPC 定向更新

`stree` 在启动时会创建一个 Unix Socket，并将其路径暴露在环境变量 `$STREE_SOCK` 中。
外部脚本可以通过以下命令向指定窗口推送数据：

```bash
# 重新生成数据并推送到 MainTree 窗口
./generate-data.sh | stree update MainTree

# 直接推送纯文本到 Preview 窗口
echo "Hello World" | stree update Preview
```
引擎接收到 IPC 数据后，仅解析并更新目标组件的状态，随后触发该组件的局部重绘。

## 样式引擎 (--status-col)

通过 `--status-col` 配置标签到样式的映射规则。语法为 `pattern=style`，多个规则用逗号分隔。

**示例**：
```bash
--status-col "live=white,archived=gray,note=blue,inbox=cyan,^fail.*=red,bold"
```
*   **精确匹配**：`live=white`（当 Tags 中包含 `live` 时，文字变白）。
*   **正则匹配**：`^fail.*=red`（当 Tags 中包含以 `fail` 开头的标签时，文字变红）。
*   **样式叠加**：`bold` 可附加在颜色后。
*   **优先级**：规则从左到右匹配，**后命中的规则覆盖先命中的规则**。因此，应将最高优先级的样式（如 `archived`）放在最后。

## 交互范式

### 键盘导航 (Vim 范式)
| 按键 | 行为 |
| :--- | :--- |
| `j` / `k` | 上下移动光标 (在 View 窗口则滚动内容) |
| `g` / `G` | 跳转到顶部 / 底部 |
| `h` / `l` | 折叠 / 展开当前节点 |
| `Space` | 标记/取消标记当前节点 (进入多选模式) |
| `Tab` | 在多个非 Status 窗口间切换焦点 |
| `/` | 进入搜索模式 (内存级实时过滤，保留树形层级) |
| `n` / `N` | 跳转到下一个 / 上一个匹配项 |
| `Esc` | 退出搜索模式 / 清除搜索词 |
| `q` | 退出程序 (退出时将最终选中的 ID 输出到 stdout) |

### 鼠标支持
*   **左键单击**：选中节点 / 切换窗口焦点。
*   **左键双击**：展开/折叠节点。
*   **右键单击**：标记/取消标记节点。
*   **滚轮**：滚动当前鼠标悬停的窗口内容（批量移动，避免重复 fork）。

## 架构红线 (Kernel Design Principles)

`stree` 引擎严格遵守以下架构宪法，任何违背这些原则的 PR 都将被拒绝：
1.  **绝不硬编码业务路径或命令**。
2.  **绝不内嵌业务校验逻辑**（如 DAG 环检测、数据去重）。
3.  **绝不读取业务专属缓存文件**（所有数据必须通过标准流或 IPC 注入）。
4.  **绝不持久化任何状态**（引擎是无状态的纯函数映射，重启即重置）。
5.  **提供机制，不提供策略**（引擎提供标签匹配机制，但不定义标签的业务语义）。
